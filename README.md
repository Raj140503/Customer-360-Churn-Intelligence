# Customer 360° & Churn Intelligence Platform

An end-to-end customer analytics, retention intelligence, and machine learning platform built using **Python, SQL, PostgreSQL, Machine Learning, and Power BI**.

The project transforms transactional retail data into customer-level insights, churn predictions, retention risk scores, and actionable business recommendations.

---

## Project Overview

Customer churn is a major business challenge because losing existing customers can directly affect revenue and long-term customer value.

This project builds a complete analytics pipeline that:

- Cleans and validates transactional sales data
- Performs customer-level aggregation
- Builds a **Customer 360° view**
- Calculates customer behavior and churn indicators
- Performs **RFM/customer segmentation**
- Predicts future customer churn using machine learning
- Generates retention risk and opportunity scores
- Identifies high-value customers requiring retention attention
- Presents executive and operational insights through Power BI

---

## Business Objectives

The platform is designed to answer questions such as:

- How much revenue is generated by the customer base?
- Which customers are active, at risk, or churned?
- Which customers are most likely to churn in the future?
- How much revenue is exposed to churn risk?
- Which high-value customers should receive retention attention first?
- Which customer segments contribute the most revenue?
- How effectively can machine learning identify future churn?

## Data Source

The project uses the **UCI Online Retail Dataset**, containing transactional data from a UK-based online retailer.

The original dataset contains:

- Invoice number
- Product/stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

The dataset covers transactions from **December 2010 to December 2011**.

Source:

**UCI Machine Learning Repository — Online Retail Dataset**

The raw dataset is intentionally not included in this repository to keep the repository lightweight. It can be downloaded from the original UCI source and processed using the project pipeline.

## Customer 360° Analytics

A customer-level dataset was created containing metrics such as:

- Total orders
- Total items purchased
- Total revenue
- Average order value
- First purchase date
- Last purchase date
- Recency
- Frequency
- Churn status

### Customer churn classification

Customers were classified based on purchase recency:

| Status | Definition |
|---|---|
| Active | 0–60 days |
| At Risk | 61–120 days |
| Churned | 121+ days |

This provides a simple business-oriented view of current customer engagement.

---

## RFM Segmentation

Customers were segmented using behavioral purchasing characteristics.

Segments include:

- Champions
- Potential Loyalists
- Loyal Customers
- New / Promising
- At Risk
- Lost Customers

The segmentation helps identify customers with different retention and growth strategies.

---

## Machine Learning

The project uses machine learning to predict whether a customer will experience **future churn**.

### Models evaluated

- Logistic Regression
- Random Forest

### Evaluation

The models were evaluated using:

- Accuracy
- ROC-AUC
- Precision
- Recall
- F1-score

The primary leakage-free Logistic Regression model achieved:

| Metric | Score |
|---|---:|
| Accuracy | **68.79%** |
| ROC-AUC | **73.54%** |

The model was designed using historical customer behavior to predict a future churn outcome, reducing target leakage compared with simply predicting the current churn label from current-state features.

---

## Churn Model Insights

The Logistic Regression model identified several important behavioral relationships.

Higher historical order frequency was strongly associated with lower future churn probability, while higher historical recency was associated with increased churn risk.

The model therefore provides both:

1. **Predictive insight** — who is likely to churn?
2. **Behavioral insight** — which customer behaviors are associated with churn?

---

## Retention Intelligence

The ML churn probability is converted into retention risk and opportunity information.

Risk categories include:

- Low Risk
- Moderate Risk
- High Risk
- Critical Risk

A **Retention Opportunity Score** combines churn risk with historical customer value to prioritize customers where retention action could have the greatest potential business impact.

This enables a shift from:

> "Which customers might churn?"

to:

> "Which customers should the business prioritize for retention?"

---

## Key Business Findings

Some of the major findings from the analysis include:

- **4,338 customers** in the Customer 360 dataset
- Approximately **£8.89M** in customer revenue
- Current customer churn rate of approximately **28.01%**
- Predicted future churn rate of approximately **53.02%**
- Top 10% of customers generated approximately **61.41% of total revenue**
- Champions generated approximately **64.48% of customer revenue**
- High-value customers represent a significant retention opportunity
- Customer revenue is highly concentrated, making targeted retention more valuable than treating every customer equally

## Reproducibility

### 1. Clone the repository

```bash
git clone <repository-url>
cd customer-360-churn-intelligence
```

### 2. Create a Python environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

If a `requirements.txt` file is provided:

```bash
pip install -r requirements.txt
```

### 4. Add the raw dataset

Download the UCI Online Retail dataset and place the source file in:

```text
data/raw/
```

### 5. Run the ETL and analysis pipeline

Use the scripts/notebooks inside:

```text
etl/
analysis/
sql/
```

to reproduce the processed datasets and analytical outputs.

### 6. Open the Power BI report

Open:

```text
reports/Customer_360_Churn_Intelligence.pbix
```

and refresh the data sources if necessary.
